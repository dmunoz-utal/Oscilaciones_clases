📖 Fundamentos Teóricos de Vibraciones y Fourier

1. Sistema de 1 Grado de Libertad (Vibración Libre y Amortiguada)

La 2ª Ley de Newton para un oscilador masa-resorte con amortiguamiento viscoso en vibración libre establece:

$$m \ddot{x}(t) + c \dot{x}(t) + k x(t) = 0 \quad \iff \quad \ddot{x}(t) + 2\zeta \omega_n \dot{x}(t) + \omega_n^2 x(t) = 0$$

Con frecuencia natural \(\omega_n = \sqrt{k/m}\) y razón de amortiguamiento \(\zeta = \frac{c}{2\sqrt{km}} = \frac{c}{c_c}\), el movimiento ante condiciones iniciales \(x(0)=x_0\) y \(\dot{x}(0)=v_0\) se clasifica en:

  • Libre No Amortiguado (\(c = 0, \zeta = 0\)): Oscilación armónica pura indefinida: \(x(t) = x_0 \cos(\omega_n t) + \frac{v_0}{\omega_n} \sin(\omega_n t) = X_0 \cos(\omega_n t - \phi_0)\).
  • Subamortiguado (\(0 < \zeta < 1\)): Oscilación sinusoidal con envolvente exponencial decreciente \(\pm C e^{-\zeta \omega_n t}\) a la frecuencia amortiguada \(\omega_d = \omega_n \sqrt{1 - \zeta^2}\): $$x(t) = e^{-\zeta \omega_n t} \left( x_0 \cos(\omega_d t) + \frac{v_0 + \zeta \omega_n x_0}{\omega_d} \sin(\omega_d t) \right)$$
  • Críticamente Amortiguado (\(\zeta = 1, c = c_c = 2\sqrt{km}\)): Retorno óptimo y más rápido al equilibrio estático sin oscilar (\(x(t) = (x_0 + (v_0 + \omega_n x_0)t)e^{-\omega_n t}\)).
  • Sobreamortiguado (\(\zeta > 1, c > c_c\)): Disipación excesiva con respuesta aperiódica lenta formada por la suma de dos exponenciales reales decrecientes.

2. Sistema de 2 Grados de Libertad (Vibración Libre Acoplada)

Las ecuaciones de movimiento acopladas para dos masas vibrando libremente se expresan en forma matricial homogénea:

$$\mathbf{M} \ddot{\mathbf{x}} + \mathbf{C} \dot{\mathbf{x}} + \mathbf{K} \mathbf{x} = \mathbf{0}$$

Para el sistema conservativo (\(\mathbf{C} = \mathbf{0}\)), proponiendo la forma armónica \(\mathbf{x}(t) = \boldsymbol{\phi} e^{i \omega t}\), se obtiene la ecuación característica:

$$\det(\mathbf{K} - \omega^2 \mathbf{M}) = 0$$

Esta ecuación entrega dos frecuencias naturales (\(\omega_{n1}\) y \(\omega_{n2}\)) y sus respectivos modos normales de vibración (autovectores \(\boldsymbol{\phi}_1, \boldsymbol{\phi}_2\)):

  • Primer Modo (\(\omega_{n1}\)): Ambas masas oscilan en la misma dirección (en fase).
  • Segundo Modo (\(\omega_{n2}\)): Las masas oscilan en sentidos opuestos (en contrafase), existiendo un punto nodal intermedio.
  • Batimiento (Transferencia de Energía): Al excitar una sola masa (\(x_1(0) > 0, x_2(0) = 0\)), se produce una modulación de amplitud donde la energía oscila continuamente de una masa a la otra a la frecuencia de batimiento \(\omega_b = |\omega_{n2} - \omega_{n1}| / 2\).
  • Amortiguamiento: La matriz \(\mathbf{C}\) disipa gradualmente la energía mecánica, reduciendo las amplitudes de ambos modos hasta el reposo.

3. Transformada de Fourier y Reconstrucción Espectral

La Transformada Discreta de Fourier (FFT) convierte la respuesta temporal \(x(t)\) en componentes sinusoidales elementales:

$$\hat{x}(t) = \bar{x} + \sum_{k=1}^N A_k \cos(\omega_k t + \phi_k)$$

Al seleccionar los \(N\) componentes con mayor contenido energético, se observa cómo la suma armónica converge rápidamente a la señal observada, permitiendo descomponer fenómenos complejos como el batimiento o la superposición modal.
